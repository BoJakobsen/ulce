# ULCE (Useless Lisp CPU Emulator)

A project aimed at learning more (Emacs)-lisp and studying the construction of simple Virtual Machines.

Initial work is on the extremely small and generally useless VM from [Advent of Code 2024 day 17th](https://adventofcode.com/2024/day/17).

Development history
- *AOC_17_2024.el* Basic version using hand written op-code table
- *AOC_17_2024_macro_version.el* Rewrite using lisp-macros.
